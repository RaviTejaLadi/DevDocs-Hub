# 💰 Profit and Loss

## Introduction

Profit and Loss is one of the most frequently asked topics in Quantitative Aptitude. It is widely used in banking exams, SSC, railway exams, placement tests, CAT, and day-to-day business calculations.

This chapter focuses on buying price, selling price, profit, loss, discounts, marked price, and related concepts.

---

## 🎯 Learning Objectives

After completing this chapter, you will be able to:

* Understand Cost Price and Selling Price
* Calculate Profit and Loss
* Find Profit % and Loss %
* Solve Discount problems
* Calculate Marked Price
* Solve advanced Profit & Loss questions

---

# Basic Terminology

## Cost Price (CP)

The price at which an item is purchased.

### Example

```text
A shopkeeper buys a book for ₹500.
```

```text
CP = ₹500
```

---

## Selling Price (SP)

The price at which an item is sold.

### Example

```text
A book is sold for ₹650.
```

```text
SP = ₹650
```

---

## Profit

When Selling Price is greater than Cost Price.

Formula:

```text
Profit = SP - CP
```

### Example

```text
CP = ₹500
SP = ₹650
```

```text
Profit = 650 - 500

= ₹150
```

---

## Loss

When Cost Price is greater than Selling Price.

Formula:

```text
Loss = CP - SP
```

### Example

```text
CP = ₹700
SP = ₹600
```

```text
Loss = 700 - 600

= ₹100
```

---

# Profit Percentage

Formula:

```text
Profit %

= (Profit / CP) × 100
```

---

## Example

```text
CP = ₹400
SP = ₹500
```

Profit:

```text
500 - 400

= ₹100
```

Profit %:

```text
(100 / 400) × 100

= 25%
```

**Answer:** 25%

---

# Loss Percentage

Formula:

```text
Loss %

= (Loss / CP) × 100
```

---

## Example

```text
CP = ₹800
SP = ₹720
```

Loss:

```text
800 - 720

= ₹80
```

Loss %:

```text
(80 / 800) × 100

= 10%
```

**Answer:** 10%

---

# Finding Selling Price

## When Profit % is Given

Formula:

```text
SP = CP × (100 + Profit %) / 100
```

---

### Example

```text
CP = ₹1000

Profit = 20%
```

```text
SP = 1000 × 120/100

= ₹1200
```

---

## When Loss % is Given

Formula:

```text
SP = CP × (100 - Loss %) / 100
```

---

### Example

```text
CP = ₹800

Loss = 25%
```

```text
SP = 800 × 75/100

= ₹600
```

---

# Finding Cost Price

## When Profit % and SP are Given

Formula:

```text
CP = SP × 100 / (100 + Profit %)
```

---

### Example

```text
SP = ₹600

Profit = 20%
```

```text
CP = 600 × 100 / 120

= ₹500
```

---

## When Loss % and SP are Given

Formula:

```text
CP = SP × 100 / (100 - Loss %)
```

---

### Example

```text
SP = ₹450

Loss = 10%
```

```text
CP = 450 × 100 / 90

= ₹500
```

---

# Discount

A discount is a reduction in the marked price.

Formula:

```text
Discount = MP - SP
```

Where:

* MP = Marked Price
* SP = Selling Price

---

## Discount Percentage

Formula:

```text
Discount %

= (Discount / MP) × 100
```

---

### Example

```text
MP = ₹1000

SP = ₹850
```

Discount:

```text
1000 - 850

= ₹150
```

Discount %:

```text
(150 / 1000) × 100

= 15%
```

**Answer:** 15%

---

# Marked Price

The price printed on a product before any discount.

Formula:

```text
MP = SP + Discount
```

---

### Example

```text
SP = ₹900

Discount = ₹100
```

```text
MP = 900 + 100

= ₹1000
```

---

# Successive Discounts

When multiple discounts are applied one after another.

Formula:

```text
Net Discount

= a + b - (ab/100)
```

Where:

* a = First Discount
* b = Second Discount

---

## Example

Discounts:

```text
20% and 10%
```

```text
20 + 10 - (20×10)/100

= 30 - 2

= 28%
```

**Answer:** 28%

---

# Important Shortcuts

## Profit Shortcut

If Profit = x%

```text
SP : CP

= (100 + x) : 100
```

### Example

Profit = 25%

```text
SP : CP

= 125 : 100

= 5 : 4
```

---

## Loss Shortcut

If Loss = x%

```text
SP : CP

= (100 - x) : 100
```

### Example

Loss = 20%

```text
SP : CP

= 80 : 100

= 4 : 5
```

# Solved Examples

## Example 1

A trader buys a pen for ₹40 and sells it for ₹50.

Find profit percentage.

Solution:

```text
Profit = 50 - 40

= ₹10
```

```text
Profit %

= (10/40) × 100

= 25%
```

**Answer:** 25%

---

## Example 2

An item is bought for ₹1200 and sold for ₹1080.

Find loss percentage.

Solution:

```text
Loss = 1200 - 1080

= ₹120
```

```text
Loss %

= (120/1200) × 100

= 10%
```

**Answer:** 10%

---

## Example 3

A product costing ₹800 is sold at 15% profit.

Find selling price.

Solution:

```text
SP

= 800 × 115/100

= ₹920
```

**Answer:** ₹920

---

## Example 4

A shirt marked ₹2000 is sold at 20% discount.

Find selling price.

Solution:

```text
SP

= 2000 × 80/100

= ₹1600
```

**Answer:** ₹1600

---

## Example 5

A shopkeeper gives successive discounts of 10% and 20%.

Find equivalent discount.

Solution:

```text
10 + 20 - (10×20)/100

= 30 - 2

= 28%
```

**Answer:** 28%

# Practice Questions

## Easy

1. Find profit when CP = ₹500 and SP = ₹650.
2. Find loss when CP = ₹800 and SP = ₹700.
3. Calculate profit percentage if CP = ₹200 and SP = ₹250.
4. Find discount if MP = ₹1000 and SP = ₹850.
5. Find selling price of an item costing ₹400 with 25% profit.

---

## Medium

1. Find CP if SP = ₹720 and profit = 20%.
2. Find SP if CP = ₹1200 and loss = 10%.
3. A product marked ₹2500 is sold at 12% discount. Find SP.
4. Calculate loss percentage when CP = ₹900 and SP = ₹765.
5. Find equivalent discount of 15% and 10%.

---

## Hard

1. A trader gains 20% by selling a product for ₹600. Find CP.
2. A shopkeeper marks goods 30% above cost and gives 10% discount. Find profit percentage.
3. Two successive discounts of 25% and 20% are offered. Find net discount.
4. A product is sold at 15% loss for ₹1700. Find CP.
5. Find SP when MP = ₹5000 and discount = 18%.

---

# Common Exam Mistakes

❌ Calculating profit percentage on SP instead of CP.

❌ Confusing Marked Price with Cost Price.

❌ Adding successive discounts directly.

❌ Using wrong denominator in percentage calculations.

---

# Exam Tips

✅ Always use Cost Price as the base for Profit % and Loss %.

✅ Memorize SP–CP shortcut ratios.

✅ Practice discount questions regularly.

✅ Convert percentages into fractions for faster calculations.

✅ Read the question carefully before applying formulas.

---

# Key Takeaways

* Profit occurs when SP > CP.
* Loss occurs when CP > SP.
* Profit % = (Profit ÷ CP) × 100.
* Loss % = (Loss ÷ CP) × 100.
* Discount is calculated on Marked Price.
* Successive discounts cannot be added directly.
* Profit & Loss is one of the highest-weightage aptitude topics.
