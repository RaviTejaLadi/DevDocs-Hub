# Vue.js Cheat Sheet (Vue 3) 🚀

| Topic                  | Syntax                              | Description                        |
| ---------------------- | ----------------------------------- | ---------------------------------- |
| Create App             | `createApp(App).mount('#app')`      | Creates and mounts Vue application |
| Single File Component  | `<template> <script setup> <style>` | Standard Vue component structure   |
| Template Interpolation | `{{ message }}`                     | Display reactive data              |
| Attribute Binding      | `:src="imageUrl"`                   | Dynamic attribute binding          |
| Shorthand Bind         | `:class="activeClass"`              | Same as `v-bind:class`             |
| Event Binding          | `@click="handleClick"`              | Same as `v-on:click`               |
| Conditional Render     | `v-if="show"`                       | Render only if condition is true   |
| Else Condition         | `v-else`                            | Alternative block                  |
| Else If                | `v-else-if="age > 18"`              | Multiple conditions                |
| Visibility Toggle      | `v-show="visible"`                  | Hides using CSS display property   |
| Looping                | `v-for="item in items"`             | Iterate arrays                     |
| Loop with Index        | `v-for="(item,index) in items"`     | Access index                       |
| Key Attribute          | `:key="item.id"`                    | Improves DOM updates               |
| Two-Way Binding        | `v-model="name"`                    | Sync input and state               |
| Text Binding           | `v-text="message"`                  | Alternative to interpolation       |
| HTML Binding           | `v-html="htmlContent"`              | Render raw HTML                    |

# Reactivity

| API             | Example                     | Description                       |
| --------------- | --------------------------- | --------------------------------- |
| ref             | `const count = ref(0)`      | Primitive reactive value          |
| Access Ref      | `count.value`               | Access/update ref value in JS     |
| reactive        | `const user = reactive({})` | Reactive object                   |
| readonly        | `readonly(state)`           | Immutable state                   |
| shallowRef      | `shallowRef(obj)`           | Tracks only top-level changes     |
| shallowReactive | `shallowReactive(obj)`      | Shallow object reactivity         |
| triggerRef      | `triggerRef(myRef)`         | Force update                      |
| isRef           | `isRef(value)`              | Check if value is ref             |
| unref           | `unref(count)`              | Get raw value                     |
| toRef           | `toRef(obj,'name')`         | Create ref from property          |
| toRefs          | `toRefs(state)`             | Convert object properties to refs |

# Watchers

| API             | Example                   | Use                     |
| --------------- | ------------------------- | ----------------------- |
| watch           | `watch(count, callback)`  | Watch specific state    |
| watchEffect     | `watchEffect(() => {})`   | Auto-track dependencies |
| Immediate Watch | `{ immediate: true }`     | Run instantly           |
| Deep Watch      | `{ deep: true }`          | Watch nested objects    |
| Stop Watch      | `const stop = watch(...)` | Cleanup watcher         |

```js
watch(count, (newVal, oldVal) => {
  console.log(newVal)
})
```

| --------- | ------------------------------ |

| Modifier   | Usage                        |
| ---------- | ---------------------------- |
| `.prevent` | Prevent default              |
| `.stop`    | Stop propagation             |
| `.once`    | Execute once                 |
| `.capture` | Capture mode                 |
| `.self`    | Only target element          |
| `.passive` | Better scrolling performance |

| State        | `state: () => ({})` |
| Getter       | `getters:{}`        |

```js

      this.user = user
    }
  }
})
```

# Most Common Vue Interview Questions

| Question                   | Answer                                             |
| -------------------------- | -------------------------------------------------- |
| ref vs reactive            | `ref` for primitives, `reactive` for objects       |
| v-if vs v-show             | `v-if` removes DOM, `v-show` hides with CSS        |
| computed vs watch          | computed derives value, watch handles side effects |
| Props vs Emits             | Parent → Child data, Child → Parent events         |
| Pinia vs Vuex              | Pinia is lighter and recommended for Vue 3         |
| Composition vs Options API | Composition API offers better code reuse           |
