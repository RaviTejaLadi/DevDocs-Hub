# ✨ Pseudo-classes & Pseudo-elements

Pseudo-classes and pseudo-elements let you style elements based on their
**state**, **position**, or **specific parts** without adding extra HTML.

Think of them as special selectors that make your CSS smarter and cleaner.

---

## What are Pseudo-classes?

A pseudo-class targets an element in a particular state.

Syntax:

/* Basic example showing the core idea. */
```css
selector:pseudo-class {
  property: value;
}
```

Example:

/* Basic example showing the core idea. */
```css
button:hover {
  background-color: blue;
}
```

When the user hovers over the button, the background changes.

## 🖱 :hover

Applies styles when the mouse is over an element.

/* Basic example showing the core idea. */
```css
a:hover {
  color: red;
}
```

<!-- Basic example showing the core idea. -->
```html
<a href="#">Hover Me</a>
```

## 👆 :active

Applies while an element is being clicked.

/* Basic example showing the core idea. */
```css
button:active {
  transform: scale(0.95);
}
```

## ⌨ :focus

Applies when an input receives focus.

/* Basic example showing the core idea. */
```css
input:focus {
  border-color: blue;
  outline: none;
}
```

<!-- Basic example showing the core idea. -->
```html
<input type="text" placeholder="Enter Name" />
```

## ✅ :checked

Targets checked checkboxes and radio buttons.

/* Basic example showing the core idea. */
```css
input:checked {
  accent-color: green;
}
```

<!-- Basic example showing the core idea. -->
```html
<input type="checkbox" checked />
```

## 🚫 :disabled

Targets disabled form controls.

/* Basic example showing the core idea. */
```css
button:disabled {
  opacity: 0.5;
  cursor: not-allowed;
}
```

## :first-child

Selects the first child element.

/* Basic example showing the core idea. */
```css
li:first-child {
  font-weight: bold;
}
```

<!-- Basic example showing the core idea. -->
```html
<ul>
  <li>First</li>
  <li>Second</li>
</ul>
```

## :last-child

Selects the last child element.

/* Basic example showing the core idea. */
```css
li:last-child {
  color: red;
}
```

## :nth-child()

Selects elements based on position.

/* Basic example showing the core idea. */
```css
li:nth-child(2) {
  color: blue;
}
```

Even rows:

/* Basic example showing the core idea. */
```css
tr:nth-child(even) {
  background: #f5f5f5;
}
```

Odd rows:

/* Basic example showing the core idea. */
```css
tr:nth-child(odd) {
  background: #eee;
}
```

## :not()

Selects everything except matching elements.

/* Basic example showing the core idea. */
```css
p:not(.highlight) {
  color: gray;
}
```

## What are Pseudo-elements?

Pseudo-elements style a specific part of an element.

/* Basic example showing the core idea. */
```css
selector::pseudo-element {
  property: value;
}
```

Notice the double colon `::`.

## ::before

Adds content before an element.

/* Basic example showing the core idea. */
```css
.title::before {
  content: '🔥 ';
}
```

<!-- Basic example showing the core idea. -->
```html
<h2 class="title">Trending</h2>
```

Output:

// Example demonstrating ✨ Pseudo-classes & Pseudo-elements.
```text
🔥 Trending
```

## ::after

Adds content after an element.

/* Basic example showing the core idea. */
```css
.title::after {
  content: ' 🚀';
}
```

// Example demonstrating ✨ Pseudo-classes & Pseudo-elements.
```text
Trending 🚀
```

## ✨ ::first-letter

Styles the first letter.

/* Basic example showing the core idea. */
```css
p::first-letter {
  font-size: 2rem;
  font-weight: bold;
}
```

## ::first-line

Styles only the first line.

/* Basic example showing the core idea. */
```css
p::first-line {
  color: blue;
}
```

## ::selection

Styles highlighted text.

/* Basic example showing the core idea. */
```css
::selection {
  background: yellow;
  color: black;
}
```

## ::placeholder

Styles placeholder text.

/* Basic example showing the core idea. */
```css
input::placeholder {
  color: gray;
}
```

## Real-World Card Example

<!-- Basic example showing the core idea. -->
```html
<div class="card">New Product</div>
```

/* Basic example showing the core idea. */
```css
.card::before {
  content: '🆕 ';
}

.card:hover {
  transform: translateY(-5px);
}
```

Result:

- Shows a "New" badge
- Lifts the card on hover

No extra HTML required.

## Useful Form Example

<!-- Basic example showing the core idea. -->
```html
<input type="email" required />
```

/* Basic example showing the core idea. */
```css
input:focus {
  border-color: blue;
}

input:invalid {
  border-color: red;
}

input:valid {
  border-color: green;
}
```

This provides instant validation feedback.

## :is()

Reduces repetition.

/* Basic example showing the core idea. */
```css
:is(h1, h2, h3) {
  color: navy;
}
```

Instead of:

/* Basic example showing the core idea. */
```css
h1,
h2,
h3 {
  color: navy;
}
```

## :where()

Like `:is()` but adds zero specificity.

/* Basic example showing the core idea. */
```css
:where(.card .title) {
  margin: 0;
}
```

Useful in large projects.

## :has() ⭐

Parent selector.

/* Basic example showing the core idea. */
```css
.card:has(img) {
  padding: 20px;
}
```

Selects cards containing images.

Modern browsers now support it.

## Quick Cheat Sheet

| Pseudo-class | Purpose                   |
| ------------ | ------------------------- |
| :hover       | Mouse hover               |
| :active      | Click state               |
| :focus       | Input focus               |
| :checked     | Checked inputs            |
| :disabled    | Disabled controls         |
| :first-child | First child               |
| :last-child  | Last child                |
| :nth-child() | Specific position         |
| :not()       | Exclude elements          |
| :is()        | Group selectors           |
| :where()     | Zero specificity grouping |
| :has()       | Parent selector           |

| Pseudo-element | Purpose          |
| -------------- | ---------------- |
| ::before       | Content before   |
| ::after        | Content after    |
| ::first-letter | First letter     |
| ::first-line   | First line       |
| ::selection    | Selected text    |
| ::placeholder  | Placeholder text |

## ✅ Best Practices

- Use pseudo-elements to avoid unnecessary HTML.
- Use `:focus` for accessibility.
- Prefer `:is()` and `:where()` for cleaner selectors.
- Use `:has()` carefully on large DOM trees.
- Keep hover effects subtle and performant.

## Key Takeaways

- Pseudo-classes target element states and positions.
- Pseudo-elements target specific parts of elements.
- They reduce extra markup and improve maintainability.
- Modern selectors like `:is()`, `:where()`, and `:has()` make CSS more powerful
  than ever.

## Syntax vs. Behavior

Syntax shows how to write the feature; behavior explains what the runtime actually does. Learn both. Pay attention to scope, evaluation order, return values, mutation, exceptions, and asynchronous behavior when they apply. These details are where small-looking examples often become surprising.

## Practical Edge Cases

Test empty input, invalid input, duplicate values, missing properties, and error paths when the feature accepts user or external data. A short example is useful for learning syntax, but a realistic example should also show validation and a predictable result.
