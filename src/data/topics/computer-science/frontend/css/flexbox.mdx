# 🔲 Flexbox

**Flexbox (Flexible Box Layout)** is a one-dimensional layout system that makes
it easy to align, distribute, and space items inside a container.

Before Flexbox, creating layouts often required floats, positioning hacks, or
complex CSS. Flexbox simplifies all of that.

---

## Why Use Flexbox?

Flexbox helps you:

✅ Center elements easily

✅ Create responsive layouts

✅ Distribute space automatically

✅ Align items vertically and horizontally

✅ Reorder elements without changing HTML

## Flex Container and Flex Items

To use Flexbox, set a container's display to `flex`.

<!-- Basic example showing the core idea. -->
```html
<div class="container">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
</div>
```

/* Basic example showing the core idea. */
```css
/* Create a flex container */
.container {
  display: flex;
}
```

The parent becomes a **flex container**, and its children become **flex items**.

## 📏 Main Axis and Cross Axis

Flexbox works using two axes:

<!-- Visual flow for 🔲 Flexbox. -->
```mermaid
flowchart TB
    MA["Main Axis → → →"]
    subgraph container["Flex Container"]
        direction LR
        i1[Flex item]
        i2[Flex item]
        i3[Flex item]
    end
    CA["Cross Axis ↓"]

MA ~~~ container
    container ~~~ CA
```

By default:

- Main Axis → Horizontal
- Cross Axis → Vertical

## ➡ flex-direction

Controls the direction of flex items.

/* Basic example showing the core idea. */
```css
.container {
  display: flex;
  flex-direction: row;
}
```

/* Basic example showing the core idea. */
```css

## column

.container {

```

## justify-content

Aligns items along the **main axis**.

/* Basic example showing the core idea. */
```css
.container {
  justify-content: center;
}
```





## space-evenly

Equal spacing everywhere.

## align-items

Aligns items on the **cross axis**.

/* Basic example showing the core idea. */
```css
.container {
  align-items: center;
}
```

(top aligned)

(vertical center)

(bottom aligned)

## stretch (Default)

Items stretch to fill the container height.

/* Basic example showing the core idea. */
```css
.container {
  align-items: stretch;
}
```

## Perfect Centering

One of Flexbox's most popular use cases.

/* Basic example showing the core idea. */
```css
/* Center content both horizontally and vertically */
.container {
  display: flex;
  justify-content: center;
  align-items: center;

height: 100vh;
}
```

## flex-wrap

Controls whether items wrap onto new lines.

## nowrap (Default)

/* Basic example showing the core idea. */
```css
.container {
  flex-wrap: nowrap;
}
```

Items stay on one line.

## wrap

/* Basic example showing the core idea. */
```css
.container {
  flex-wrap: wrap;
}
```

Items move to a new line if necessary.

## wrap-reverse

/* Basic example showing the core idea. */
```css
.container {
  flex-wrap: wrap-reverse;
}
```

Wraps in reverse order.

## gap

Adds spacing between flex items.

/* Basic example showing the core idea. */
```css
.container {
  display: flex;
  gap: 20px;
}
```

Better than using margins.

## 📈 flex-grow

Controls how items expand.

/* Basic example showing the core idea. */
```css
.item {
  flex-grow: 1;
}
```

Example:

/* Basic example showing the core idea. */
```css
.item1 {
  flex-grow: 1;
}

.item2 {
  flex-grow: 2;
}
```

Result:

// Example demonstrating 🔲 Flexbox.
```text
Item 2 is twice as wide as Item 1
```

## 📉 flex-shrink

Controls how items shrink.

/* Basic example showing the core idea. */
```css
.item {
  flex-shrink: 1;
}
```

Default value is `1`.

## 📏 flex-basis

Defines the initial size of an item.

/* Basic example showing the core idea. */
```css
.item {
  flex-basis: 200px;
}
```

## The flex Shorthand

Instead of:

/* Basic example showing the core idea. */
```css
.item {
  flex-grow: 1;
  flex-shrink: 1;
  flex-basis: 0;
}
```

Use:

/* Basic example showing the core idea. */
```css
.item {
  flex: 1;
}
```

Very common in layouts.

## 🔢 order

Changes visual order without changing HTML.

/* Basic example showing the core idea. */
```css
.item1 {
  order: 3;
}

.item2 {
  order: 1;
}

.item3 {
  order: 2;
}
```

Display order:

// Example demonstrating 🔲 Flexbox.
```text
Item2
Item3
Item1
```

## align-self

Overrides alignment for a single item.

/* Basic example showing the core idea. */
```css
.item {
  align-self: flex-end;
}
```

Only that item moves.

## 📱 Responsive Row Layout

/* Basic example showing the core idea. */
```css
/* Responsive flex layout */
.container {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
}

.item {
  flex: 1 1 300px;
}
```

Each item:

- Grows
- Shrinks
- Starts at 300px

### Forgetting `display: flex`

Won't work.

You must use:

/* Basic example showing the core idea. */
```css
.container {
  display: flex;
}
```

### Using Margins Instead of Gap

❌

/* Basic example showing the core idea. */
```css
.item {
  margin-right: 20px;
}
```

✅

/* Basic example showing the core idea. */
```css
.container {
  gap: 20px;
}
```

### Mixing Up Axes

Remember:

// Example demonstrating 🔲 Flexbox.

## ✅ Best Practices

- Use Flexbox for one-dimensional layouts.
- Use `gap` instead of margins for spacing.
- Prefer `flex: 1` for equal-width items.
- Use `wrap` for responsive layouts.
- Combine Flexbox with media queries for mobile support.

## Key Takeaways

- Flexbox is designed for one-dimensional layouts.
- `justify-content` controls the main axis.
- `align-items` controls the cross axis.
- `gap` creates clean spacing.
- `flex-grow`, `flex-shrink`, and `flex-basis` control sizing.
- Flexbox makes alignment and responsiveness much easier.
