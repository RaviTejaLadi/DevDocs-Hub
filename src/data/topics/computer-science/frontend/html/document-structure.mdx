# 📄 HTML Document Structure

Every HTML page follows a standard document structure. Think of it like the
blueprint of a house 🏠. The structure tells the browser how to organize and
display the content on a web page.

### Basic HTML Document Structure

<!-- Basic example showing the core idea. -->
```html
<!-- Basic HTML document structure -->
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>My First Web Page</title>
  </head>
  <body>
    <h1>Welcome to HTML</h1>
    <p>This is my first web page.</p>
  </body>
</html>
```

---

### 1. `<!DOCTYPE html>`

<!-- Basic example showing the core idea. -->
```html
<!DOCTYPE html>
```

- Declares that the document is an HTML5 document.
- Must be the first line of every HTML page.
- Helps browsers render the page correctly.

### 2. `<html>` Element

<!-- Basic example showing the core idea. -->
```html
<html lang="en"></html>
```

- The root element of an HTML document.
- All other elements are placed inside it.
- The `lang` attribute specifies the language of the page.

Example:

<!-- Basic example showing the core idea. -->
```html
<html lang="fr"></html>
```

### 3. `<head>` Section

<!-- Basic example showing the core idea. -->
```html
<head>
  ...
</head>
```

The `<head>` contains metadata about the webpage.

This information is not displayed directly on the page but is used by browsers
and search engines.

### 4. Character Encoding

<!-- Basic example showing the core idea. -->
```html
<meta charset="UTF-8" />
```

- Defines the character encoding.
- UTF-8 supports most languages and symbols.

Supports:

- English
- తెలుగు
- हिंदी
- العربية
- Emojis 😊

### 5. Viewport Meta Tag

<!-- Basic example showing the core idea. -->
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

- Makes websites responsive.
- Ensures proper display on mobile devices.

Without it, pages may appear zoomed out on smartphones.

### 6. `<title>` Element

<!-- Basic example showing the core idea. -->
```html
<title>My First Web Page</title>
```

- Sets the page title.
- Appears in the browser tab.
- Important for SEO.

<!-- Basic example showing the core idea. -->
```html
<title>HTML Tutorial for Beginners</title>
```

Browser Tab:

// Example demonstrating 📄 HTML Document Structure.
```text
HTML Tutorial for Beginners
```

### 7. `<body>` Section

<!-- Basic example showing the core idea. -->
```html
<body>
  ...
</body>
```

- Contains all visible content.
- Everything users see goes inside the body.

Examples:

<!-- Basic example showing the core idea. -->
```html
<body>
  <h1>Heading</h1>
  <p>Paragraph</p>
  <img src="image.jpg" alt="Image" />
  <button>Click Me</button>
</body>
```

## 📋 Real-World Example

<!-- Basic example showing the core idea. -->
```html
<!-- Portfolio webpage structure -->
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>John Doe Portfolio</title>
  </head>
  <body>
    <header>
      <h1>John Doe</h1>
    </header>

<main>
      <p>Frontend Developer</p>
    </main>

<footer>
      <p>© 2026 John Doe</p>
    </footer>
  </body>
</html>
```

### Missing DOCTYPE

❌ Wrong

<!-- Basic example showing the core idea. -->
```html
<html>
  <body>
    <h1>Hello</h1>
  </body>
</html>
```

✅ Correct

<!-- Basic example showing the core idea. -->
```html
<!DOCTYPE html>
<html>
  <body>
    <h1>Hello</h1>
  </body>
</html>
```

### Missing Title

<!-- Basic example showing the core idea. -->
```html
<head> </head>
```

<!-- Basic example showing the core idea. -->
```html
<head>
  <title>My Website</title>
</head>
```

### Content Outside Body

<!-- Basic example showing the core idea. -->
```html
<h1>Hello World</h1>

<body></body>
```

<!-- Basic example showing the core idea. -->
```html
<body>
  <h1>Hello World</h1>
</body>
```

## Quick Summary

| Element           | Purpose                               |
| ----------------- | ------------------------------------- |
| `<!DOCTYPE html>` | Defines HTML5 document                |
| `<html>`          | Root element                          |
| `<head>`          | Metadata and settings                 |
| `<meta>`          | Character encoding and responsiveness |
| `<title>`         | Browser tab title                     |
| `<body>`          | Visible page content                  |

### Simple Formula to Remember

// Example demonstrating 📄 HTML Document Structure.
```text
DOCTYPE
   ↓
HTML
 ├── HEAD (information about page)
 └── BODY (content shown to users)
```

💡 **Tip:** Every HTML page you create should start with this structure. It
provides a solid foundation for adding headings, images, links, forms, CSS, and
JavaScript later.

## Syntax vs. Behavior

Syntax shows how to write the feature; behavior explains what the runtime actually does. Learn both. Pay attention to scope, evaluation order, return values, mutation, exceptions, and asynchronous behavior when they apply. These details are where small-looking examples often become surprising.

## Practical Edge Cases

Test empty input, invalid input, duplicate values, missing properties, and error paths when the feature accepts user or external data. A short example is useful for learning syntax, but a realistic example should also show validation and a predictable result.

## Maintainable Usage

Prefer the clearest correct construct before reaching for clever shortcuts. Keep transformations small, name intermediate values when they improve readability, and avoid hidden side effects. In revision notes, the goal is not only to remember a feature but also to know when using it makes the code easier to understand.
