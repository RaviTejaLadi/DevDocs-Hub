# Files & Folder Structure (Vue 3 + Vite)

## Introduction

A good folder structure helps with:

- Scalability
- Maintainability
- Reusability
- Team collaboration
- Clean architecture
- Easier debugging

Modern Vue applications usually follow a **feature-driven + modular structure**.

---

## src/main.js

Application entry point.

This is where Vue app starts.

- Mount application
