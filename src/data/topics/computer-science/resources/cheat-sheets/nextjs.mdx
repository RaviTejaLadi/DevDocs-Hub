# Next.js

Next.js is a React framework for building full-stack web applications with
Server Components, API routes, SSR, SSG, and modern routing.

---

## Project Creation

| Command                      | Description              |
| ---------------------------- | ------------------------ |
| `npx create-next-app@latest` | Create project           |
| `npm run dev`                | Start development server |
| `npm run build`              | Production build         |
| `npm run start`              | Run production server    |
| `npm run lint`               | Run ESLint               |

# Basic example showing the core idea.
```bash
## Create a Next.js project
npx create-next-app@latest my-app
```

## Production Best Practices

| Practice                 | Why                    |
| ------------------------ | ---------------------- |
| Prefer Server Components | Smaller JS bundle      |
| Use Server Actions       | Avoid API boilerplate  |
| Use Image Component      | Automatic optimization |
| Use Metadata API         | Better SEO             |
| Cache Fetch Requests     | Better performance     |
| Lazy Load Components     | Faster pages           |
| Keep Secrets on Server   | Security               |
| Use Suspense             | Better UX              |

## Most Asked Next.js Interview Questions

| Question                   | Answer                                        |
| -------------------------- | --------------------------------------------- |
| App Router vs Pages Router | App Router is the modern approach             |
| Server vs Client Component | Server runs on server, Client runs in browser |
| SSR vs SSG                 | SSR per request, SSG at build time            |
| ISR                        | Rebuild pages incrementally                   |
| Server Actions             | Execute server code from forms                |
| Route Handlers             | API endpoints in App Router                   |
| Middleware                 | Runs before requests                          |
| Streaming                  | Send UI progressively                         |
| Suspense                   | Async UI loading                              |
| Revalidation               | Refresh cached data                           |
