# TypeScript Cheat Sheet 🚀

TypeScript adds static typing on top of JavaScript. It helps catch errors early,
improves IDE support, and makes large applications easier to maintain.

---

# Basic Types

| Type      | Example                        | Description             |
| --------- | ------------------------------ | ----------------------- |
| string    | `let name: string = "Ravi"`    | Text value              |
| number    | `let age: number = 25`         | Integer/float           |
| boolean   | `let active: boolean = true`   | True/false              |
| null      | `let data: null = null`        | Null value              |
| undefined | `let value: undefined`         | Undefined value         |
| bigint    | `let id: bigint = 100n`        | Large numbers           |
| symbol    | `const key: symbol = Symbol()` | Unique identifier       |
| any       | `let x: any`                   | Disable type checking   |
| unknown   | `let x: unknown`               | Safe alternative to any |
| never     | `function fail(): never`       | Never returns           |
| void      | `function log(): void`         | No return value         |

```ts
// Basic types
let username: string = 'John';
let age: number = 25;
let isAdmin: boolean = false;
```

# Interface vs Type

| Interface           | Type          |
| ------------------- | ------------- |
| Extendable          | Yes           |
| Declaration Merging | Yes           |
| Union Support       | No            |
| Complex Types       | Limited       |
| Recommended For     | Object shapes |

# Type Narrowing

```ts
function print(id: string | number) {
  if (typeof id === 'string') {
    console.log(id.toUpperCase());
  }
}
```

### Common Narrowing

| Method       | Example                     |
| ------------ | --------------------------- |
| typeof       | `typeof value === "string"` |
| instanceof   | `value instanceof Date`     |
| in           | `"name" in obj`             |
| Custom Guard | `isUser(data)`              |

# Type Guards

```ts
interface User {
  name: string;
}

function isUser(data: any): data is User {
  return data?.name !== undefined;
}
```

# Generics

Generics create reusable type-safe code.

```ts
function identity<T>(value: T): T {
  return value;
}
```

```ts
identity<string>('hello');
identity<number>(100);
```

# Generic Constraints

```ts
interface HasId {
  id: number;
}

function getId<T extends HasId>(item: T) {
  return item.id;
}
```
