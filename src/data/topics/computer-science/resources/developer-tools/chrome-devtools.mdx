# Chrome DevTools

Chrome DevTools helps developers inspect, debug, and optimize web applications
directly from the browser.

### Keyboard Shortcuts

| Action          | Windows/Linux    | Mac              |
| --------------- | ---------------- | ---------------- |
| Open DevTools   | F12              | Cmd + Option + I |
| Inspect Element | Ctrl + Shift + C | Cmd + Shift + C  |

---

## 🧱 Elements Panel

The Elements tab allows you to inspect and modify HTML and CSS.

### Common Tasks

- Inspect DOM structure
- Edit HTML live
- Add/remove classes
- Test CSS changes
- Check computed styles

### Example

Inspect:

<div class="card">Hello World</div>

You can edit text or styles instantly without changing source code.

### View Applied Styles

Select an element and check:

- Styles
- Computed
- Layout

Useful for finding:

- CSS overrides
- Specificity issues
- Missing styles

### Force States

Right-click element → Force State

Simulate:

- :hover
- :focus
- :active

## 📱 Responsive Design Mode

Click:

Toggle Device Toolbar

Ctrl + Shift + M

Test:

- Mobile devices

Useful for responsive UI testing.

## Console Panel

The Console is used for:

- Debugging JavaScript
- Running commands
- Viewing logs

### Examples

console.log("Hello");

console.table(users);

console.error("Something went wrong");

### Add Breakpoints

1. Open Sources tab
2. Select JS file
3. Click line number

Execution pauses at breakpoint.

### Controls

| Action    | Shortcut    |
| --------- | ----------- |
| Resume    | F8          |
| Step Over | F10         |
| Step Into | F11         |
| Step Out  | Shift + F11 |

## ⏱ Performance Tab

Record page activity.

Useful for:

- Slow rendering
- Re-renders
- Layout shifts
- CPU bottlenecks

### Workflow

1. Open Performance
2. Click Record
3. Interact with page
4. Stop recording
5. Analyze timeline

Tools:

- Heap Snapshot
- Allocation Timeline

## 🚨 Common Debugging Workflow

1. Open Network tab
2. Reproduce issue
3. Verify API response
4. Check Console errors
5. Inspect DOM changes
6. Debug JavaScript
7. Analyze performance

This workflow solves most frontend bugs quickly.

## ⭐ Pro Tips

- Preserve logs during page refresh
- Disable cache while debugging
- Use console.table() for arrays
- Use breakpoints instead of excessive console.log()
- Filter network requests by Fetch/XHR
- Save performance recordings for analysis

Mastering DevTools can dramatically reduce debugging time and improve
application performance.

## Decision Guide

Connect the definition to a practical decision: what problem does the concept solve, what assumptions does it make, and what evidence tells you it is working? This turns a memorised sentence into a usable mental model.

## Compare Related Ideas

When two concepts look similar, compare their purpose, inputs, guarantees, lifecycle, and trade-offs. A short comparison is often more useful for revision than another paragraph repeating the same definition.

## Self-Check

After reading an example, change one input and predict the result before running it. Then explain what changed and why. This exposes gaps in understanding and gives you a quick test without needing a separate exercise set.

## Practical Decision

A concept becomes easier to revise when it is tied to a decision you may actually make. Identify the problem, the available choices, and the condition that makes one choice appropriate. Then state one case where the concept should not be used. That negative example is useful because it marks the boundary of the idea and reduces confusion with related concepts.
