# npm, Yarn & pnpm

npm, Yarn, and pnpm are JavaScript package managers used to install, update, and
manage project dependencies.

They help developers:

- Install packages
- Manage versions
- Run scripts
- Share projects easily

---

## What is a Package Manager?

Instead of manually downloading libraries:

lodash axios react

You can install them with a single command.

Example:

npm install axios

The package manager downloads and manages dependencies automatically.

## npm

npm comes bundled with Node.js.

Check version:

npm -v

Initialize project:

npm init

Skip prompts:

npm init -y

## 🧶 Yarn

Yarn was created to improve:

- Speed
- Reliability
- Dependency resolution

yarn -v

yarn init

## pnpm

pnpm focuses on:

- Faster installs
- Less disk usage
- Better monorepo support

pnpm -v

Create project:

pnpm init



### Yarn

yarn add axios


pnpm add axios

## 📋 Package.json

Central project configuration file.

{ "name": "my-app", "version": "1.0.0", "scripts": { "dev": "vite", "build":
"vite build" } }

- Metadata

## Lock Files

Package managers generate lock files.

package-lock.json

yarn.lock

pnpm-lock.yaml

Purpose:

- Consistent installs
- Reproducible builds
- Prevent version mismatches

Always commit lock files.

## Why pnpm is Fast

Traditional approach:

Project A └── node_modules

Project B └── node_modules

Same package downloaded multiple times.

pnpm:

Global Store ├── react ├── axios └── vite

Projects use links to the store.

Benefits:

- Faster installs
- Reduced disk space
- Better performance

## 🏢 Monorepo Support

pnpm is widely used for:

- Turborepo
- Nx
- Large-scale applications

Example structure:

apps/ ├── web ├── admin

packages/ ├── ui ├── utils

pnpm handles shared dependencies efficiently.

## ⭐ Which One Should You Use?

Good for:

- Beginners
- Small projects
- Default Node.js setup

- Existing Yarn projects
- Teams already using Yarn

- React applications
- Monorepos
- Large codebases
- Faster installations

For modern React and Next.js projects, pnpm is often the preferred choice
because of its performance, efficient storage usage, and excellent workspace
support.
