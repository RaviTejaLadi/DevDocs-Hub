# ⏳ Time & Work

Time & Work is one of the most important aptitude topics for placements and
competitive exams. Most questions revolve around:

- Work Efficiency
- Individual Work
- Combined Work
- Pipes & Cisterns
- Wages
- Work and Time Relationships

The key idea is:

> More efficiency → Less time required Less efficiency → More time required

---

## Basic Concept

If a person completes a work in **n days**:

// Example demonstrating ⏳ Time & Work.
```text
One day's work = 1/n
```

Example:

A completes a work in 10 days.

// Example demonstrating ⏳ Time & Work.
```text
One day's work = 1/10
```

Meaning A finishes 1/10th of the work every day.

## Fundamental Formula

// Example demonstrating ⏳ Time & Work.
```text
Work = Efficiency × Time
```

From this:

// Example demonstrating ⏳ Time & Work.
```text
Time = Work / Efficiency
```

// Example demonstrating ⏳ Time & Work.
```text
Efficiency = Work / Time
```

## Example 1

A can complete a work in 20 days.

Find work done in 1 day.

// Example demonstrating ⏳ Time & Work.
```text
1/20
```

✅ Answer: **1/20**

## Example 2

A completes 1/15 of work daily.

Find total days.

// Example demonstrating ⏳ Time & Work.
```text
1 ÷ (1/15)

= 15
```

✅ Answer: **15 days**

## Efficiency Concept

Efficiency is inversely proportional to time.

Formula:

// Example demonstrating ⏳ Time & Work.
```text
Efficiency ∝ 1/Time
```

A finishes work in:

B finishes work in:

// Example demonstrating ⏳ Time & Work.
```text
20 days
```

Efficiency ratio:

// Example demonstrating ⏳ Time & Work.
```text
20 : 10

= 2 : 1
```

✅ A is twice as efficient as B.

## LCM Method (Most Important Shortcut)

Instead of assuming work = 1, assume work = LCM of days.

This avoids fractions.

A completes work in:

// Example demonstrating ⏳ Time & Work.
```text
12 days
```

B completes work in:

// Example demonstrating ⏳ Time & Work.
```text
18 days
```

Take total work:

// Example demonstrating ⏳ Time & Work.
```text
LCM(12,18)

= 36 units
```

Efficiency:

// Example demonstrating ⏳ Time & Work.
```text
A = 36/12 = 3 units/day
```

// Example demonstrating ⏳ Time & Work.
```text
B = 36/18 = 2 units/day
```

Combined:

// Example demonstrating ⏳ Time & Work.
```text
5 units/day
```

// Example demonstrating ⏳ Time & Work.
```text
36/5

= 7.2 days
```

✅ Answer: **7.2 days**
