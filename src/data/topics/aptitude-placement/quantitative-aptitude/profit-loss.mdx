# 💰 Profit & Loss

Profit & Loss is one of the most scoring topics in Quantitative Aptitude. It is
frequently asked in:

- Campus Placements
- Banking Exams
- SSC
- CAT
- Railway Exams
- Government Exams

Most questions are based on simple formulas and percentage concepts.

---

## Cost Price (CP)

The price at which an item is purchased.

Example:

```text
A shopkeeper buys a mobile for ₹15,000.
```

Then:

```text
CP = ₹15,000
```

## Selling Price (SP)

The price at which an item is sold.

```text
Mobile sold for ₹18,000
```

```text
SP = ₹18,000
```

## Profit (Gain)

When Selling Price is greater than Cost Price.

Formula:

```text
Profit = SP - CP
```

```text
CP = ₹500
SP = ₹650

Profit = 650 - 500
       = ₹150
```

✅ Profit = ₹150

## Loss

When Cost Price is greater than Selling Price.

```text
Loss = CP - SP
```

```text
CP = ₹800
SP = ₹700

Loss = 800 - 700
     = ₹100
```

✅ Loss = ₹100

## Profit Percentage

```text
Profit % = (Profit / CP) × 100
```

```text
CP = ₹1000
SP = ₹1200
```

Profit:

```text
1200 - 1000 = 200
```

Profit %:

```text
(200/1000) × 100
= 20%
```

✅ Profit = 20%

## Loss Percentage

```text
Loss % = (Loss / CP) × 100
```

```text
CP = ₹1000
SP = ₹850
```

Loss:

```text
1000 - 850 = 150
```

Loss %:

```text
(150/1000) × 100
= 15%
```

✅ Loss = 15%

## When Profit % is Given

```text
SP = CP × (100 + Profit%)/100
```

```text
CP = ₹2000
Profit = 25%
```

```text
SP = 2000 × 125/100
   = ₹2500
```

✅ SP = ₹2500

## When Loss % is Given

```text
SP = CP × (100 - Loss%)/100
```

```text
CP = ₹4000
Loss = 10%
```

```text
SP = 4000 × 90/100
   = ₹3600
```

✅ SP = ₹3600

## Given SP and Profit %

```text
CP = (SP × 100)/(100 + Profit%)
```

```text
SP = ₹2400
Profit = 20%
```

```text
CP = (2400 × 100)/120
   = ₹2000
```

✅ CP = ₹2000

## Given SP and Loss %

```text
CP = (SP × 100)/(100 - Loss%)
```

```text
SP = ₹1600
Loss = 20%
```

```text
CP = (1600 × 100)/80
   = ₹2000
```

## 🏷 Marked Price (MP)

Marked Price is the price printed on the product.

Also called:

- List Price
- Catalog Price

```text
MP = ₹1000
```

## 🏷 Discount

Discount is the reduction from the Marked Price.

```text
Discount = MP - SP
```

```text
MP = ₹1000
SP = ₹900
```

```text
Discount = 1000 - 900
         = ₹100
```

✅ Discount = ₹100

## Discount Percentage

```text
Discount % = (Discount / MP) × 100
```

```text
MP = ₹2000
SP = ₹1600
```

Discount:

```text
2000 - 1600
= 400
```

Discount %:

```text
(400/2000) × 100
= 20%
```

✅ Discount = 20%

## Selling Price After Discount

```text
SP = MP × (100 - Discount%)/100
```

```text
MP = ₹5000
Discount = 30%
```

```text
SP = 5000 × 70/100
   = ₹3500
```

✅ SP = ₹3500

## 🔥 Successive Discounts

When more than one discount is given.

```text
Net Discount

= a + b - (ab/100)
```

Example

Discounts:

```text
20% and 10%
```

```text
20 + 10 - (20×10)/100

= 28%
```

✅ Net Discount = 28%

## Profit on Marked Price Questions

```text
CP = ₹800
MP = ₹1200
Discount = 10%
```

Find Profit %.

Step 1:

Find SP

```text
SP = 1200 × 90/100

= ₹1080
```

Step 2:

Profit

```text
1080 - 800

= ₹280
```

Step 3:

Profit %

```text
(280/800) × 100

= 35%
```

✅ Profit = 35%

## Profit of x%

CP : SP

```text
100 : (100 + x)
```

20% Profit

```text
100 : 120

5 : 6
```

## Loss of x%

```text
100 : (100 - x)
```

20% Loss

```text
100 : 80

5 : 4
```

## Dishonest Shopkeeper Questions

These are common in aptitude exams.

A shopkeeper claims to sell at CP but uses a 900g weight instead of 1kg.

Actual gain:

```text
Gain %

= [(1000 - 900)/900] × 100

= 11.11%
```

✅ Gain = 11.11%

## False Weight Formula

If x grams sold as 1000 grams:

```text
Profit %

= [(1000 - x)/x] × 100
```

## Question 1

An article is bought for ₹800 and sold for ₹920.

Solution:

```text
Profit = 920 - 800
       = 120
```

```text
Profit % = (120/800) × 100
         = 15%
```

✅ Answer: 15%

## Question 2

An article is sold at 20% loss for ₹400.

Find CP.

```text
CP = (400 × 100)/80

= ₹500
```

✅ Answer: ₹500

## Question 3

Marked price is ₹2500.

Discount = 20%.

Find SP.

```text
SP = 2500 × 80/100

= ₹2000
```

✅ Answer: ₹2000

## Question 4

Two successive discounts of 20% and 10%.

Find net discount.

✅ Answer: 28%

## Question 5

An article is sold at 25% profit.

If CP = ₹1200, find SP.

```text
SP = 1200 × 125/100

= ₹1500
```

✅ Answer: ₹1500

### Mistake 1

Calculating profit percentage using SP.

Wrong:

```text
Profit % = Profit/SP × 100
```

Correct:

```text
Profit % = Profit/CP × 100
```

### Mistake 2

Adding discounts directly.

```text
20% + 10% = 30%
```

### Mistake 3

Confusing Marked Price and Cost Price.

Remember:

```text
CP → Purchase price
MP → Printed price
SP → Selling price
```

## Exam-Oriented Shortcuts

Memorize:

```text
20% Profit → CP:SP = 5:6
25% Profit → CP:SP = 4:5
50% Profit → CP:SP = 2:3

20% Loss → CP:SP = 5:4
25% Loss → CP:SP = 4:3
50% Loss → CP:SP = 2:1
```

These save a lot of calculation time.
