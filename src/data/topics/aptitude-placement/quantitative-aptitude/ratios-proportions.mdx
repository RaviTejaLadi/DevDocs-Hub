# ⚖ Ratio & Proportion

Ratio and Proportion are fundamental topics in Quantitative Aptitude. They are
heavily used in:

- Percentages
- Profit & Loss

- Partnership
- Mixtures & Alligations
- Data Interpretation

Understanding this topic makes many aptitude questions much easier.

## What is a Ratio?

A **ratio** is a comparison of two quantities having the same units.

Formula:

// Example demonstrating ⚖ Ratio & Proportion.
```text
Ratio = First Quantity : Second Quantity
```

Example:

If there are 20 boys and 30 girls in a class:

// Example demonstrating ⚖ Ratio & Proportion.
```text
Ratio of Boys : Girls

= 20 : 30

= 2 : 3
```

✅ Answer: **2 : 3**

## Parts of a Ratio

In:

// Example demonstrating ⚖ Ratio & Proportion.
```text
3 : 5
```

- First term = 3 (Antecedent)
- Second term = 5 (Consequent)

## What is Proportion?

A proportion states that two ratios are equal.

```text
a : b = c : d
// Example demonstrating ⚖ Ratio & Proportion.
```

or

```text
a/b = c/d
// Example demonstrating ⚖ Ratio & Proportion.
```

```text
2 : 4 = 3 : 6
// Example demonstrating ⚖ Ratio & Proportion.
```

Because:

```text
2/4 = 3/6
// Example demonstrating ⚖ Ratio & Proportion.
```

Both equal:

```text
1/2
// Example demonstrating ⚖ Ratio & Proportion.
```

## Direct Proportion

When one quantity increases, the other also increases.

Examples:

- More workers → More work done
- More quantity → More cost

```text
x₁/x₂ = y₁/y₂
// Example demonstrating ⚖ Ratio & Proportion.
```

### Example

5 books cost ₹100.

What is the cost of 10 books?

```text
5/10 = 100/x
// Example demonstrating ⚖ Ratio & Proportion.
```

```text
5x = 1000
// Example demonstrating ⚖ Ratio & Proportion.
```

```text
x = ₹200
// Example demonstrating ⚖ Ratio & Proportion.
```

✅ Answer: ₹200

## Inverse Proportion

When one quantity increases, the other decreases.

- More workers → Less time
- Higher speed → Less travel time

```text
x₁ × y₁ = x₂ × y₂
// Example demonstrating ⚖ Ratio & Proportion.
```

10 workers complete a job in 12 days.

How many days will 15 workers take?

```text
10 × 12 = 15 × x
// Example demonstrating ⚖ Ratio & Proportion.
```

```text
120 = 15x
// Example demonstrating ⚖ Ratio & Proportion.
```

✅ Answer: 8 days

### Mistake 1

Adding ratios directly.

Wrong:

// Example demonstrating ⚖ Ratio & Proportion.
```text
2:3 + 4:5
```

Use compound ratio when required.

### Mistake 2

Using direct proportion instead of inverse proportion.

Remember:

// Example demonstrating ⚖ Ratio & Proportion.
```text
Workers ↑
Time ↓
```

Inverse relationship.

### Mistake 3

Ignoring simplification.

Always reduce ratios to simplest form.

// Example demonstrating ⚖ Ratio & Proportion.
```text
12 : 18
```

## ✅ Summary

Ratio compares quantities, while proportion compares ratios. Important concepts
include:

- Simplifying ratios
- Compound and continued ratios
- Direct and inverse proportion
- Mean, third, and fourth proportionals
- Partnership problems
- Age-based ratio questions
- Percentage ↔ Ratio conversions

These concepts are widely used in Time & Work, Profit & Loss, and Data
Interpretation.
