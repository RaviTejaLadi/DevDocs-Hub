## What is a Percentage?

Percentage means **"per hundred"**.

The symbol `%` represents percentage.

```text
1% = 1/100
```

Example:

```text
25% = 25/100 = 1/4
```

```text
50% = 50/100 = 1/2
```

```text
75% = 75/100 = 3/4
```

## Percentage Formula

```text
Percentage = (Part / Whole) × 100
```

A class has 40 students.

20 are girls.

Find the percentage of girls.

```text
Percentage = (20 / 40) × 100

= 50%
```

✅ Answer: 50%

```text

```

Examples:

```text

```

```text

```

```text

## Finding Percentage of a Number

```text
x% of y

= (x/100) × y
```

Example 1

Find 20% of 500.

```text
20/100 × 500

= 100
```

✅ Answer: 100

Example 2

Find 15% of 200.

```text
15/100 × 200

= 30
```

✅ Answer: 30

## Shortcut Method

Find 25% of 800.

Since:

```text
25% = 1/4
```

```text
800 ÷ 4

= 200
```

✅ Faster than using formula.

## Percentage Increase

```text
Increase %

= (Increase / Original Value) × 100
```

Price increases from ₹500 to ₹600.

Increase:

```text
600 - 500

Percentage increase:

```text
(100/500) × 100

= 20%
```

✅ Answer: 20%

```
## Percentage Decrease

```text
Decrease %

= (Decrease / Original Value) × 100
```

Price decreases from ₹800 to ₹600.

Decrease:

```text
800 - 600

Percentage decrease:

```text
(200/800) × 100

= 25%
```

✅ Answer: 25%

```
## Increase by x%

New Value:

```text
Original × (100 + x)/100
```

Increase ₹1000 by 20%.

```text
1000 × 120/100

= 1200
```

## Decrease by x%

```text
Original × (100 - x)/100
```

Decrease ₹1000 by 20%.

```text
1000 × 80/100

= 800
```

## Successive Percentage Change

When multiple percentage changes occur one after another.

```text
Net Change

= a + b + (ab/100)
```

Example

Increase by 20% and then 10%.

```text
20 + 10 + (20×10)/100

= 32%
```

✅ Net increase = 32%

Increase by 20% and decrease by 10%.

```text
20 - 10 - (20×10)/100

= 8%
```

✅ Net increase = 8%

```text

### Multiplication Shortcuts

```text
20% of N = N/5
25% of N = N/4
50% of N = N/2
75% of N = 3N/4
```

### Mistake 1

Using final value instead of original value.

Always divide by the original value when calculating percentage
increase/decrease.

### Mistake 2

Adding percentages directly.

Wrong:

```text
+20% and -20%
```

Correct:

```text
20 - 20 - (20×20)/100

= -4%
```

Net decrease = 4%
