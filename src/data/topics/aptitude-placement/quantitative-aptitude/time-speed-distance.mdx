# ⏱ Time, Speed & Distance (TSD)

Time, Speed & Distance is one of the most important aptitude topics for
placements and competitive exams. Most questions are based on a few simple
formulas, but the challenge is applying them quickly.

Common question types:

- Basic Speed, Distance, Time
- Average Speed
- Relative Speed
- Trains
- Boats & Streams
- Circular Tracks
- Races

---

## Basic Concepts

There are three fundamental quantities:

- Distance (D)
- Speed (S)
- Time (T)

Relationship:

```text
Distance = Speed × Time
```

From this:

```text
Speed = Distance / Time
```

```text
Time = Distance / Speed
```

### Speed Conversion

```text
1 m/s = 18/5 km/hr
```

```text
1 km/hr = 5/18 m/s
```

## Example

Convert 72 km/hr into m/s.

```text
72 × 5/18

= 20 m/s
```

✅ Answer: 20 m/s

Convert 15 m/s into km/hr.

```text
15 × 18/5

= 54 km/hr
```

✅ Answer: 54 km/hr

## Example 1

A car travels at 60 km/hr for 3 hours.

Find distance.

```text
Distance = Speed × Time

= 60 × 3

= 180 km
```

✅ Answer: 180 km

## Example 2

A train covers 240 km in 4 hours.

Find speed.

```text
Speed = 240/4

= 60 km/hr
```

✅ Answer: 60 km/hr

## Average Speed

Many students make mistakes here.

Formula:

```text
Average Speed

= Total Distance / Total Time
```

A car travels:

```text
60 km at 30 km/hr
```

and

```text
60 km at 60 km/hr
```

Time taken:

```text
60/30 = 2 hr
```

```text
60/60 = 1 hr
```

Total:

```text
Distance = 120 km

Time = 3 hr
```

Average Speed:

```text
120/3

= 40 km/hr
```

✅ Answer: 40 km/hr

## 🌊 Boats and Streams

A favorite topic in aptitude exams.

### Downstream

Boat moves with current.

```text
Downstream Speed

= Boat Speed + Stream Speed
```

### Upstream

Boat moves against current.

```text
Upstream Speed

= Boat Speed - Stream Speed
```

## Finding Boat Speed

```text
Boat Speed

= (Downstream + Upstream)/2
```

Downstream:

```text
20 km/hr
```

Upstream:

```text
12 km/hr
```

```text
(20 + 12)/2

= 16 km/hr
```

✅ Boat Speed = 16 km/hr

## Finding Stream Speed

```text
Stream Speed

= (Downstream - Upstream)/2
```

```text
(20 - 12)/2

= 4 km/hr
```

✅ Stream Speed = 4 km/hr

## If Speed Increases

Time decreases.

```text
Speed ∝ 1/Time
```

Speed increases by:

```text
25%
```

New speed:

```text
125%
```

Time ratio:

```text
100 : 125

= 4 : 5
```

New time decreases by:

```text
20%
```

## Speed Change Formula

If speed increases by x%.

Time decrease:

```text
[x/(100+x)] × 100
```

Speed increases:

```text
25/125 × 100

= 20%
```

✅ Answer: 20%

### Mistake 1

Using average of speeds as average speed.

Wrong:

```text
(30+60)/2

= 45
```

Correct:

```text
40 km/hr
```

when distances are equal.

### Mistake 2

Not converting units.

```text
Length → meters
Speed → km/hr
```

Always convert before solving.

### Mistake 3

Using sum instead of difference for same-direction trains.

Remember:

```text
Same Direction → Difference
```

```text
Opposite Direction → Sum
```

```

```text

```

```text
Boat Speed = (D+U)/2
```

```text
Stream Speed = (D-U)/2
```

These shortcuts solve most placement questions within seconds.
