# Gravitation

### Statement

Every particle of matter in the universe attracts every other particle with a
force directly proportional to the product of their masses and inversely
proportional to the square of the distance between them.

### Equation

// Example demonstrating Gravitation.
```
F = G(m₁m₂)/r²
```

Where:

- G = 6.67 × 10⁻¹¹ N⋅m²/kg²
- r = distance between centers

### Vector Form

// Example demonstrating Gravitation.
```
F₁₂ = -G(m₁m₂)r̂/r²
```

### Definition

// Example demonstrating Gravitation.
```
g = F/m = GM/r²
```

### Field Lines

- Point toward mass
- Strength decreases as 1/r²

### Gravitational Potential

// Example demonstrating Gravitation.
```
V = -GM/r
```

### Gravitational Potential Energy

// Example demonstrating Gravitation.
```
U = -GMm/r
```

(Zero at infinity)

### Variation with Altitude

// Example demonstrating Gravitation.
```
g' = g(1 - 2h/R) for h << R
```

### Variation with Depth

// Example demonstrating Gravitation.
```
g' = g(1 - d/R)
```

Where d = depth below surface

### Variation with Latitude

- Centrifugal effect
- Earth's oblateness

### Variation with Rotation

// Example demonstrating Gravitation.
```
g_eff = g - Rω²cos²λ
```

### First Law (Law of Ellipses)

All planets move in elliptical orbits with the Sun at one focus.

### Second Law (Law of Areas)

A line segment joining a planet and the Sun sweeps out equal areas during equal
time intervals.

### Third Law (Law of Periods)

// Example demonstrating Gravitation.
```
T² ∝ a³
```

or

// Example demonstrating Gravitation.
```
T² = (4π²/GM)a³
```

### Derivation from Newton's Law

- For circular orbits: T² = (4π²/GM)r³

### Orbital Velocity

// Example demonstrating Gravitation.
```
v_orbital = √(GM/r)
```

### Escape Velocity

// Example demonstrating Gravitation.
```
v_escape = √(2GM/r)
```

### Geosynchronous Orbit

- Period = 24 hours
- Altitude ≈ 35,786 km
- Stationary relative to Earth's surface

### Types of Orbits

1. **Circular**: e = 0
2. **Elliptical**: 0 < e < 1
3. **Parabolic**: e = 1
4. **Hyperbolic**: e > 1

### Prediction

- Predicted by Einstein's theory of general relativity
- Generated by accelerating masses

### Detection

- LIGO observatory
- First detection in 2015

### Properties

- Travel at speed of light
- Transverse waves
- Quadrupole radiation

### Satellite Motion

- GPS satellites
- Communication satellites
- Weather satellites

### Spacecraft Trajectories

- Hohmann transfer orbits
- Gravity assist

### Tidal Forces

- Differential gravitational force
- Tidal bulges
- Effects of Moon and Sun

### Black Holes

- Escaped velocity > c
- Schwarzschild radius: R_s = 2GM/c²
