# 🔬 Modern Physics

## Introduction to Modern Physics

Modern physics encompasses revolutionary developments in physics from the early
20th century, including relativity, quantum mechanics, and their applications.
It fundamentally changed our understanding of space, time, matter, and energy.

### Einstein's Postulates

1. **Principle of Relativity**: The laws of physics are the same in all inertial
   reference frames.

2. **Constancy of Speed of Light**: The speed of light in vacuum is constant for
   all observers, regardless of relative motion.

#### Transformation Equations

```
x' = γ(x - vt)
t' = γ(t - vx/c²)
```

Where:

- γ = 1/√(1 - v²/c²) (Lorentz factor)
- v = relative velocity
- c = speed of light

#### Time Dilation

```
Δt' = γΔt₀
```

Moving clocks run slower.

#### Length Contraction

```
L = L₀/γ
```

Moving objects contract in direction of motion.

#### Relativistic Velocity Addition

```
u = (u' + v)/(1 + u'v/c²)
```

#### Relativistic Momentum

```
p = γmv
```

#### Relativistic Energy

```
E = γmc²
```

#### Rest Energy

```
E₀ = mc²
```

#### Kinetic Energy

```
K = (γ - 1)mc²
```

#### Total Energy

```
E² = (pc)² + (mc²)²
```

### Consequences and Applications

- GPS satellite corrections
- Particle accelerators
- Nuclear reactions
- Mass-energy equivalence

---

### Key Concepts

- Gravity is curvature of spacetime
- Mass-energy tells spacetime how to curve
- Curved spacetime tells matter how to move

### Predictions

1. **Gravitational time dilation**: Time runs slower near massive objects
2. **Gravitational redshift**: Light loses energy climbing out of gravity well
3. **Gravitational lensing**: Light bends around massive objects
4. **Black holes**: Extreme curvature of spacetime
5. **Gravitational waves**: Ripples in spacetime

### Tests of General Relativity

- Mercury's perihelion precession
- Deflection of starlight by Sun
- Time delay in radar echoes
- Gravitational wave detection (LIGO)



#### Classical Failure

- Rayleigh-Jeans law predicted infinite energy at high frequencies
- Ultraviolet catastrophe

#### Planck's Hypothesis

```
E = hf
```

- h = 6.63 × 10⁻³⁴ J·s (Planck's constant)
- f = frequency of radiation

#### Planck's Radiation Law

```
I(f,T) = (2hf³/c²)/(e^{hf/kT} - 1)
```

#### Experimental Observations

1. No photoelectrons below threshold frequency
2. KE max independent of intensity
3. No time delay
4. KE max increases with frequency

#### Einstein's Explanation

```
hf = φ + K_max
```

Where φ = work function

#### Equation

```
λ' - λ = (h/m₀c)(1 - cos θ)
```

#### Significance

- Proves particle nature of photons
- Momentum conservation of photons

#### de Broglie Wavelength

```
λ = h/p = h/(mv)
```

#### Electron Diffraction

- Davisson-Germer experiment
- Electron wave properties

#### Postulates

1. Electrons orbit in quantized orbits
2. Angular momentum: L = nh/2π
3. Energy quantized: E_n = -13.6/n² eV

#### Energy Levels

```
E_n = - (m₀e⁴)/(8ε₀²h²) × 1/n²
```

#### Bohr Radius

```
r_n = n²a₀
```

Where a₀ = 0.529 Å

#### Spectral Series

- Lyman (n = 1): UV
- Balmer (n = 2): Visible
- Paschen (n = 3): IR

#### Wave-Particle Duality

- Matter has wave-like properties
- Probability interpretation

#### Heisenberg Uncertainty Principle

```
Δx·Δp ≥ h/4π
ΔE·Δt ≥ h/4π
```

#### Schrödinger Equation

**Time-Dependent:**

```
iℏ∂Ψ/∂t = -ℏ²/2m ∂²Ψ/∂x² + VΨ
```

**Time-Independent:**

```
-ℏ²/2m ∂²ψ/∂x² + Vψ = Eψ
```

#### Wave Function (Ψ)

- Probability density: |Ψ|²
- Normalization: ∫|Ψ|² dx = 1
- Contains all information about system

### Quantum Numbers

1. **Principal (n)**: Energy level (n = 1,2,3,...)
2. **Azimuthal (l)**: Orbital shape (0 to n-1)
3. **Magnetic (m_l)**: Orbital orientation (-l to +l)
4. **Spin (m_s)**: Electron spin (±½)

### Pauli Exclusion Principle

No two electrons can have the same set of quantum numbers.

#### Fine Structure

- Spin-orbit coupling
- Relativistic corrections

#### Hyperfine Structure

- Nuclear spin effects
- 21 cm hydrogen line

#### Types of Bonds

- **Ionic**: Transfer of electrons
- **Covalent**: Sharing of electrons
- **Metallic**: Electron sea
- **Hydrogen**: Weak electrostatic

#### Molecular Spectra

- Rotational (microwave)
- Vibrational (IR)
- Electronic (UV-Visible)



#### Composition

- Protons (positive charge)
- Neutrons (neutral)
- Nucleons = protons + neutrons

#### Mass Number (A)

```
A = Z + N
```

Where Z = number of protons, N = number of neutrons

#### Nuclear Stability

- Isotope: Same Z, different N
- Isotone: Same N, different Z
- Isobar: Same A, different Z

#### Mass Defect

```
Δm = [Zm_p + Nm_n] - M_nucleus
```

#### Binding Energy

```
E_b = Δm c²
```

#### Binding Energy Curve

- Most stable: Iron (Fe-56)
- Fission: Heavy nuclei split
- Fusion: Light nuclei combine

#### Types of Radiation

| Type    | Composition       | Charge | Mass  | Stopped By     |
| ------- | ----------------- | ------ | ----- | -------------- |
| Alpha   | He-4 nucleus      | +2e    | 4 amu | Paper          |
| Beta    | Electron/Positron | ±e     | ~0    | Aluminum       |
| Gamma   | Photon            | 0      | 0     | Lead           |
| Neutron | Neutron           | 0      | 1 amu | Water/Hydrogen |

#### Radioactive Decay Law

```
N(t) = N₀e^{-λt}
```

#### Half-Life

```
T₁/₂ = ln 2/λ = 0.693/λ
```

#### Activity

```
A(t) = A₀e^{-λt}
```

Unit: 1 Becquerel = 1 decay/s

#### Types

- **Fission**: Splitting heavy nuclei

- Chain reactions
  - Applications: Nuclear reactors, bombs

- **Fusion**: Combining light nuclei

- Requires high temperatures
  - Applications: Stars, hydrogen bombs

- **Transmutation**: Changing one element to another
- **Spallation**: Breaking into fragments

#### Nuclear Energy

- Power generation
- Nuclear reactors (thermal, fast breeders)
- Radioisotope thermoelectric generators (RTGs)

#### Medical Applications

- Radiation therapy (cancer treatment)
- Nuclear medicine (diagnostic imaging)
- Radioisotopes for tracing

#### Industrial Applications

- Radiography (non-destructive testing)
- Tracers (process monitoring)
- Materials analysis

#### Weapons

- Atomic bombs (fission)
- Hydrogen bombs (fusion)
- Neutron bombs (enhanced radiation)

#### Types of Radiation Damage

- **Acute**: High dose, short term
- **Chronic**: Low dose, long term
- **Genetic**: Damage to DNA

#### Protection Principles

1. **Time**: Minimize exposure time
2. **Distance**: Maximize distance from source
3. **Shielding**: Use appropriate barriers



#### Fermions (Spin ½)

- **Quarks**: Up, down, charm, strange, top, bottom

#### Bosons (Spin 1 or 0)

- **Gauge bosons**: Photon (EM), Gluons (strong), W/Z (weak)
