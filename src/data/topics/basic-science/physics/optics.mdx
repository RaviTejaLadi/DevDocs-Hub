# Optics

## Introduction to Optics

Optics is the branch of physics that studies light and its behavior. It
encompasses reflection, refraction, diffraction, interference, and the
interaction of light with matter.



#### Particle Theory (Newton)

- Light consists of particles (corpuscles)
- Explained reflection and refraction
- Couldn't explain diffraction and interference

#### Wave Theory (Huygens)

- Light is a wave
- Explained interference and diffraction
- Required a medium (ether)

#### Electromagnetic Theory (Maxwell)

- Light is electromagnetic radiation
- Unification of electricity, magnetism, and optics
- Speed of light in vacuum is constant

#### Quantum Theory (Einstein)

- Light has particle-like properties (photons)
- Energy: E = hf
- Wave-particle duality (de Broglie)

### Speed of Light

// Example demonstrating Optics.
```
c = 3 × 10⁸ m/s (in vacuum)
v = c/n (in medium)
```

### Laws of Reflection

1. The incident ray, reflected ray, and normal lie in the same plane
2. The angle of incidence equals the angle of reflection
   ```
   θ_i = θ_r
   ```

### Types of Reflection

- **Specular reflection**: Smooth surfaces (mirrors)
- **Diffuse reflection**: Rough surfaces (paper, walls)

### Plane Mirrors

- Image formation
- Virtual image: behind the mirror
- Image characteristics:
  - Same size as object
  - Erect (upright)
  - Laterally inverted
  - Virtual
- Uses: Periscopes, kaleidoscopes

#### Types

- **Concave mirror**: Reflecting surface is inner surface
- **Convex mirror**: Reflecting surface is outer surface

#### Important Terms

- **Center of curvature (C)**: Center of sphere
- **Radius of curvature (R)**: Radius of sphere
- **Principal axis**: Line through C and pole
- **Pole (P)**: Center of mirror surface
- **Principal focus (F)**: Point where parallel rays meet (concave) or appear to
  diverge (convex)
- **Focal length (f)**: f = R/2

#### Mirror Equation

// Example demonstrating Optics.
```
1/f = 1/v + 1/u
```

Where:

- f = focal length
- v = image distance
- u = object distance (negative for real objects by sign convention)

#### Magnification

// Example demonstrating Optics.
```
m = -v/u = h_i/h_o
```

#### Ray Diagrams

- Rules for drawing rays
- Finding position, size, and nature of images

### Applications of Spherical Mirrors

- **Concave mirrors**: Reflectors, shaving mirrors, telescopes
- **Convex mirrors**: Rearview mirrors, security mirrors

### Laws of Refraction

1. The incident ray, refracted ray, and normal lie in the same plane
2. Snell's Law:
   ```
   n₁ sin θ₁ = n₂ sin θ₂
   ```

### Refractive Index (n)

// Example demonstrating Optics.
```
n = c/v
```

Where c = speed of light in vacuum, v = speed in medium

### Absolute and Relative Refractive Index

- Absolute: n = c/v (relative to vacuum)
- Relative: n₁₂ = n₂/n₁ = v₁/v₂

### Critical Angle

// Example demonstrating Optics.
```
sin θ_c = n₂/n₁
```

(For n₁ > n₂)

### Total Internal Reflection

- Occurs when θ₁ > θ_c
- Applications:
  - Fiber optics
  - Prisms
  - Mirage

### Dispersion

- Separation of white light into component colors
- Different wavelengths have different refractive indices
- Prism produces spectrum (VIBGYOR)

#### Angle of Deviation

// Example demonstrating Optics.
```
δ = i₁ + i₂ - A
```

Where A = prism angle

#### Minimum Deviation

// Example demonstrating Optics.
```
n = sin((A + δ_m)/2)/sin(A/2)
```

#### Lenses

**Types:**

- **Convex lens**: Converging lens (thicker at center)
- **Concave lens**: Diverging lens (thinner at center)

**Lens Terms:**

- Optical center
- Principal axis
- Focal point (F)
- Focal length (f)

**Lens Formula:**

// Example demonstrating Optics.
```
1/f = 1/v - 1/u
```

**Lens Maker's Formula:**

// Example demonstrating Optics.
```
1/f = (n₂/n₁ - 1)(1/R₁ - 1/R₂)
```

**Power of Lens:**

// Example demonstrating Optics.
```
P = 1/f (in meters)
```

Unit: Diopter (D)

**Magnification by Lens:**

// Example demonstrating Optics.
```
m = v/u = h_i/h_o
```

**Ray Diagrams for Lenses:**

- Rules for tracing rays
- Image formation in different cases

**Applications:**

- Cameras, projectors
- Magnifying glasses
- Eyeglasses and contact lenses
- Microscopes, telescopes

### The Human Eye

- **Structure**: Cornea, iris, pupil, lens, retina
- **Accommodation**: Changing focal length
- **Near point**: 25 cm (normal vision)
- **Far point**: Infinity (normal vision)
- **Defects of vision**:
  - Myopia (nearsightedness): Corrected with concave lens
  - Hypermetropia (farsightedness): Corrected with convex lens
  - Presbyopia: Age-related loss of accommodation
  - Astigmatism: Curvature irregularity

#### Simple Microscope (Magnifying Glass)

// Example demonstrating Optics.
```
M = D/f (angular magnification)
```

Where D = near point distance (25 cm)

#### Compound Microscope

// Example demonstrating Optics.
```
M = (L/f_o)(D/f_e)
```

- L = tube length
- f_o = objective focal length
- f_e = eyepiece focal length
- M = total magnification

#### Refracting Telescope

// Example demonstrating Optics.
```
M = f_o/f_e
```

- Keplerian (astronomical): Inverted image
- Galilean: Upright image

#### Reflecting Telescope

- Uses mirrors instead of lenses
- Advantages: No chromatic aberration, larger aperture

### Other Instruments

- **Projector**: Magnified image on screen
- **Periscope**: Uses prisms for total internal reflection
- **Spectrometer**: Measures angles of refraction



#### Young's Double Slit Experiment

- Demonstrates wave nature of light
- Bright fringes (constructive): d sin θ = nλ
- Dark fringes (destructive): d sin θ = (n + ½)λ

**Fringe Width:**

// Example demonstrating Optics.
```
β = λD/d
```

#### Coherence

- **Temporal coherence**: Phase relationship over time
- **Spatial coherence**: Phase relationship across space

#### Thin Film Interference

- Colors in soap bubbles, oil films
- Conditions for constructive/destructive interference
- Newton's rings

#### Single Slit Diffraction

- Central maximum is brightest and widest
- Minima: a sin θ = nλ
- Width of central maximum: 2λD/a

#### Diffraction Grating

// Example demonstrating Optics.
```
d sin θ = nλ
```

- Resolution: R = Nn (N = number of slits)

#### X-ray Diffraction

- Bragg's Law: 2d sin θ = nλ
- Determines crystal structure

#### Methods of Polarization

- Polarizing filters (Polaroid)
- Reflection (Brewster's angle)
- Double refraction (birefringence)
- Scattering

#### Brewster's Angle

// Example demonstrating Optics.
```
tan θ_B = n₂/n₁
```

Reflected light is completely polarized

#### Malus's Law

// Example demonstrating Optics.
```
I = I₀ cos²θ
```

Where θ = angle between transmission axis and polarization direction

#### Applications

- LCD displays
- 3D movies and glasses
- Stress analysis
- Optical communication



#### Properties

- Coherent (same phase)
- Monochromatic (single wavelength)
- Directional (narrow beam)
- High intensity

#### Components

- Active medium
- Pumping source
- Optical resonator

- Solid-state (ruby, Nd:YAG)
- Gas (He-Ne, CO₂)
- Semiconductor (laser diodes)

- Medicine (surgery, cosmetic)
- Communication (fiber optics)
- Manufacturing (cutting, welding)
- Scientific research

#### Principle

Total internal reflection in optical fibers

#### Structure

- Core (higher n)
- Cladding (lower n)
- Protective jacket

- Single-mode: One ray path
- Multimode: Multiple ray paths

- Telecommunications
- Endoscopy
- Decorative lighting
- Sensors

### Holography

- Records interference pattern of light
- 3D image reconstruction
- Applications: Security, storage, imaging

### Classical Failure

- No time delay observed
- Threshold frequency exists
- Intensity affects only current, not energy

### Einstein's Explanation

- Light consists of photons (E = hf)
- One photon ejects one electron (if E > work function)
- Kinetic energy: K_max = hf - φ (work function)


- Solar cells
- Photomultipliers
- Photocells

### Wave-Particle Duality

- Light behaves as both wave and particle
- Photons have momentum: p = h/λ
- de Broglie wavelength: λ = h/p

### Quantum Optics

- Photon statistics
- Quantum entanglement
- Quantum cryptography
- Quantum computing

### Color Mixing

- **Additive**: RGB (red, green, blue)
- **Subtractive**: CMY (cyan, magenta, yellow)

### Color Perception

- Rods: Low light levels (monochromatic)
- Cones: Bright light, color vision
- Three types of cones (S, M, L)

### Color Deficiency

- Red-green color blindness most common
- Genetic in nature
- Tests: Ishihara plates

### Rainbows

- Dispersion and total internal reflection
- Primary rainbow: One internal reflection
- Secondary rainbow: Two internal reflections

### Mirages

- Caused by refraction in temperature gradients
- Inferior mirage: Hot surface (desert)
- Superior mirage: Cold surface

### Atmospheric Refraction

- Sunrise/sunset effects
- Twinkling of stars
- Green flash

### Halos and Sundogs

- Ice crystal refraction
- 22° halo
- Sun dogs (parhelia)
