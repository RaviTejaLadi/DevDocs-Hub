# Kinematics

## Introduction to Kinematics

Kinematics is the branch of mechanics that describes motion without considering
its causes. It deals with position, velocity, acceleration, and time
relationships.

### Position and Displacement

- **Position**: Location of an object relative to a reference point
- **Displacement**: Change in position (vector quantity)
- **Distance**: Total path length traveled (scalar quantity)

### Speed and Velocity

- **Speed** = Distance/Time (scalar)
- **Velocity** = Displacement/Time (vector)
- **Average velocity** = Δx/Δt
- **Instantaneous velocity** = dx/dt

### Acceleration

- **Acceleration** = Change in velocity/Time
- **Average acceleration** = Δv/Δt
- **Instantaneous acceleration** = dv/dt

### 1D Motion Equations

```
1. v = u + at
2. s = ut + ½at²
3. v² = u² + 2as
4. s = ½(u + v)t
```

Where:

- u = initial velocity
- v = final velocity
- a = acceleration
- t = time
- s = displacement

### Free Fall

- Acceleration due to gravity: g = 9.8 m/s²
- Equations same as above with a = g
- Sign convention matters (upward positive or downward positive)

### Key Equations

- Horizontal motion: x = (v₀ cos θ)t
- Vertical motion: y = (v₀ sin θ)t - ½gt²
- Time of flight: T = 2v₀ sin θ/g
- Maximum height: H = (v₀² sin² θ)/(2g)
- Range: R = (v₀² sin 2θ)/g

### Special Cases

- θ = 90°: Vertical projectile
- θ = 45°: Maximum range
- θ = 0°: Horizontal projectile

### Position-Time Graphs

- Slope = velocity
- Curved line = acceleration
- Horizontal line = rest

### Velocity-Time Graphs

- Slope = acceleration
- Area under curve = displacement
- Horizontal line = constant velocity

### Acceleration-Time Graphs

- Area under curve = change in velocity
- Horizontal line = constant acceleration

### Key Quantities

- Angular displacement: θ
- Angular velocity: ω = dθ/dt
- Angular acceleration: α = dω/dt
- Linear velocity: v = rω
- Centripetal acceleration: aₐ = v²/r = rω²

### Period and Frequency

- Period (T): Time for one revolution
- Frequency (f): Number of revolutions per second
- ω = 2πf = 2π/T

### Relative Velocity

- Vector subtraction: v_AB = v_A - v_B
- Motion in two dimensions
- River-boat problems
- Rain-man problems

### Reference Frames

- Inertial frames
- Non-inertial frames
- Transformation between frames

### Vector Kinematics

- Position vector: r(t) = x(t)i + y(t)j + z(t)k
- Velocity vector: v(t) = dr/dt
- Acceleration vector: a(t) = dv/dt

### Curvilinear Motion

- Tangential acceleration: aₜ = dv/dt
- Normal acceleration: aₙ = v²/ρ
- Total acceleration: a = aₜ + aₙ

## Assumptions and Units

For engineering topics, write down known quantities, unknowns, units, and governing assumptions before calculating. Check the final unit and physical direction of the result. A mathematically correct expression can still be physically invalid if an assumption has been violated.

## Limiting Conditions

Pay attention to boundary conditions, material properties, environmental changes, sign conventions, and measurement error. If a formula relies on an approximation, state when that approximation is reasonable. Revision becomes much easier when each equation is attached to the condition that justifies it.

## Worked Check

After solving a numerical example, estimate the order of magnitude and compare it with a realistic range. A quick sanity check often catches unit conversion errors, misplaced decimal points, and incorrect signs.

## Model Limitations

Every engineering model is valid only within stated assumptions. Identify the operating range, approximations, and variables that can change the result. When a quantity is measured rather than exact, consider uncertainty and whether the required precision justifies the calculation. In revision, remember the relationship together with its assumptions; applying a correct equation outside its valid range can produce a physically misleading answer.
