# Properties of Matter

### Stress and Strain

- **Stress** = Force/Area
- **Strain** = Change in dimension/Original dimension
- **Elastic limit**: Maximum stress without permanent deformation

### Types of Stress

1. **Tensile**: Stretching
2. **Compressive**: Squeezing
3. **Shear**: Slicing
4. **Volumetric**: Uniform compression

### Modulus of Elasticity

- **Young's modulus** (Y) = Tensile stress/Tensile strain
- **Shear modulus** (G) = Shear stress/Shear strain
- **Bulk modulus** (B) = Volumetric stress/Volumetric strain

### Hooke's Law

// Example demonstrating Properties of Matter.
```
F = -kx
```

- Linear relationship within elastic limit
- Spring constant k

### Poisson's Ratio

// Example demonstrating Properties of Matter.
```
ν = (Lateral strain)/(Longitudinal strain)
```

### Definition

// Example demonstrating Properties of Matter.
```
P = F/A
```

### Pascal's Principle

- Pressure applied to a confined fluid is transmitted equally throughout the
  fluid
- Hydraulic systems: F₁/A₁ = F₂/A₂

### Atmospheric Pressure

- Standard atmosphere: 1 atm = 101.325 kPa
- Barometers measure atmospheric pressure
- Manometers measure gauge pressure

### Variation with Depth

// Example demonstrating Properties of Matter.
```
P = P₀ + ρgh
```

### Buoyancy

- Archimedes' Principle: Buoyant force = weight of displaced fluid
- F_b = ρ_fluid V_displaced g

### Fluid Flow

- Continuity equation: A₁v₁ = A₂v₂
- Bernoulli's Equation: P + ½ρv² + ρgh = constant

## Viscosity

- Internal friction in fluids
- Newtonian fluids: τ = η(dv/dy)

### Coefficient of Viscosity

- Unit: Pa⋅s or poise
- Temperature dependence

### Poiseuille's Equation


### Stokes' Law

// Example demonstrating Properties of Matter.
```
F_drag = 6πηrv
```

### Terminal Velocity

// Example demonstrating Properties of Matter.
```
v_ter = (2r²(ρ - ρ₀)g)/(9η)
```

## Surface Tension

- Force per unit length
- Unit: N/m or erg/cm²

### Capillary Action

// Example demonstrating Properties of Matter.
```
h = (2T cos θ)/(ρgr)
```

- Rise in capillary tube
- Meniscus formation

### Surface Energy

// Example demonstrating Properties of Matter.
```

```

### Applications

- Soaps and detergents
- Meniscus in tubes
- Floating insects

### Temperature Scales

- Celsius: °C = K - 273.15
- Fahrenheit: °F = (9/5)°C + 32
- Kelvin: K = °C + 273.15

### Thermal Expansion

- Linear: ΔL = αL₀ΔT
- Volume: ΔV = βV₀ΔT
- β ≈ 3α (for isotropic materials)

### Specific Heat Capacity

// Example demonstrating Properties of Matter.
```
Q = mcΔT
```

### Latent Heat

- Latent heat of fusion (melting/freezing)
- Latent heat of vaporization (boiling/condensation)

### Heat Transfer

1. **Conduction**: Through material
2. **Convection**: Through fluid movement
3. **Radiation**: Through electromagnetic waves

### Thermal Conductivity

// Example demonstrating Properties of Matter.
```
Q/t = kA(ΔT/L)
```

- Good conductors: metals
- Poor conductors: insulators

### Thermal Resistance

// Example demonstrating Properties of Matter.
```
R = L/(kA)
```

### Thermal Expansion of Solids and Liquids

- Bimetallic strips
- Expansion in practical applications

### Ideal Gas Behavior

// Example demonstrating Properties of Matter.
```
PV = nRT
```

- Boyle's Law: P₁V₁ = P₂V₂ (constant T)
- Charles' Law: V₁/T₁ = V₂/T₂ (constant P)
- Gay-Lussac's Law: P₁/T₁ = P₂/T₂ (constant V)

### Thermodynamic Properties

1. **Internal Energy**: Function of state
2. **Enthalpy**: H = U + PV
3. **Entropy**: Measure of disorder
4. **Free Energy**: Useful work available

### Phase Transitions

- Melting point
- Boiling point
- Sublimation
- Critical point and pressure

### Classification of Materials

1. **Metals**: Good conductors, ductile
2. **Insulators**: Poor conductors, brittle
3. **Semiconductors**: Intermediate
4. **Superconductors**: Zero resistance at low temperatures
5. **Polymers**: Long chain molecules
6. **Composite materials**: Multiple phases

## Assumptions and Units

For engineering topics, write down known quantities, unknowns, units, and governing assumptions before calculating. Check the final unit and physical direction of the result. A mathematically correct expression can still be physically invalid if an assumption has been violated.

## Limiting Conditions

Pay attention to boundary conditions, material properties, environmental changes, sign conventions, and measurement error. If a formula relies on an approximation, state when that approximation is reasonable. Revision becomes much easier when each equation is attached to the condition that justifies it.

## Worked Check

After solving a numerical example, estimate the order of magnitude and compare it with a realistic range. A quick sanity check often catches unit conversion errors, misplaced decimal points, and incorrect signs.

## Model Limitations

Every engineering model is valid only within stated assumptions. Identify the operating range, approximations, and variables that can change the result. When a quantity is measured rather than exact, consider uncertainty and whether the required precision justifies the calculation. In revision, remember the relationship together with its assumptions; applying a correct equation outside its valid range can produce a physically misleading answer.
