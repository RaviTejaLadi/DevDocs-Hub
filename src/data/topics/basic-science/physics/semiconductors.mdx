# Semiconductors

## Introduction to Semiconductors

Semiconductors are materials with electrical conductivity between conductors and
insulators. They are the foundation of modern electronics, enabling devices like
transistors, diodes, and integrated circuits.



#### Valence Band

- Highest occupied band
- Electrons in this band are bound to atoms
- Participates in chemical bonding

#### Conduction Band

- Lowest unoccupied band
- Electrons here are free to move
- Responsible for electrical conduction

#### Band Gap (E_g)

// Example demonstrating Semiconductors.
```
E_g = E_C - E_V
```

Energy difference between conduction and valence bands

#### Conductors

- No band gap
- Overlapping valence and conduction bands
- High conductivity
- Examples: Copper, silver, gold

#### Insulators

- Large band gap (> 3 eV)
- Very few electrons in conduction band
- Poor conductivity
- Examples: Glass, rubber, diamond

- Small band gap (0.1 - 3 eV)
- Moderate conductivity
- Examples: Silicon (1.12 eV), Germanium (0.67 eV)

#### Pure Semiconductors

- Perfect crystal lattice
- Equal number of electrons and holes
- Conductivity depends on temperature

#### Carrier Concentration

// Example demonstrating Semiconductors.
```
n = p = n_i = A T^{3/2} e^{-E_g/(2kT)}
```

#### Doping

- Intentional addition of impurities
- Controls conductivity type
- Creates excess electrons or holes

#### n-type Semiconductor

- Donor impurities (e.g., P, As, Sb)
- Extra electrons added
- Majority carriers: electrons
- Minority carriers: holes

#### p-type Semiconductor

- Acceptor impurities (e.g., B, Al, Ga)
- Electron holes created
- Majority carriers: holes
- Minority carriers: electrons

#### Fermi Level

- Energy at which occupation probability = ½
- In n-type: Near conduction band
- In p-type: Near valence band

#### Fermi-Dirac Distribution

// Example demonstrating Semiconductors.
```
f(E) = 1/[1 + e^{(E - E_F)/kT}]
```

#### Mass Action Law

// Example demonstrating Semiconductors.
```
n·p = n_i²
```

---



#### Formation

- Joining p-type and n-type semiconductors
- Diffusion of carriers across junction
- Depletion region formed
- Built-in potential established

#### Space Charge Region

- Positive on n-side
- Negative on p-side
- Electric field prevents further diffusion

#### Forward Bias

- Voltage applied forward (p to n)
- Current flows exponentially
- Threshold voltage (~0.7V for Si)
- V-I characteristic: I = I_s(e^{V/V_T} - 1)

#### Reverse Bias

- Voltage applied reverse (n to p)
- Small leakage current
- Breakdown at high reverse voltage

#### Diode Equation

// Example demonstrating Semiconductors.
```
I = I_s(e^{V/ηV_T} - 1)
```

Where:

- I_s = saturation current
- η = ideality factor (1-2)
- V_T = kT/q (thermal voltage, ~26mV at 300K)

#### Zener Breakdown

- High doping concentration
- Tunneling of electrons
- Sharp breakdown voltage

#### Avalanche Breakdown

- Lower doping concentration
- Impact ionization
- Less sharp breakdown

#### Applications

- Zener diodes for voltage regulation
- Avalanche diodes for protection

#### Half-Wave Rectifier

- Uses one diode
- Conducts in one half-cycle
- Efficiency: 40.6%

#### Full-Wave Rectifier

- Uses multiple diodes
- Conducts in both half-cycles
- Efficiency: 81.2%

#### Bridge Rectifier

- Four diodes
- No center-tapped transformer required
- Common in power supplies

#### Capacitor Filter

- Smooths rectified output
- Ripple voltage depends on C and load

#### LC Filter

- Better filtering
- Used in higher power applications

#### Voltage Regulation

- Zener voltage regulator
- Series voltage regulator
- Integrated circuits



#### Types

- **NPN**: Emitter (n), Base (p), Collector (n)
- **PNP**: Emitter (p), Base (n), Collector (p)

#### Regions

- Emitter: Heavily doped
- Base: Lightly doped, thin
- Collector: Moderately doped, large

#### Current Gain

// Example demonstrating Semiconductors.
```
β = I_C/I_B
α = I_C/I_E

```

#### Modes of Operation

| Mode       | E-B Junction | C-B Junction | Application |
| ---------- | ------------ | ------------ | ----------- |
| Cutoff     | Reverse      | Reverse      | Off         |
| Active     | Forward      | Reverse      | Amplifier   |
| Saturation | Forward      | Forward      | Switch      |
| Inverse    | Reverse      | Forward      | Rarely used |

#### Ebers-Moll Model

// Example demonstrating Semiconductors.
```
I_C = α_F I_F - I_{CBO}(e^{V_{CB}/V_T} - 1)
I_E = I_F - α_R I_R
```

#### Input Characteristics

- I_B vs V_BE
- Diode characteristics
- Depends on V_CE

#### Output Characteristics

- I_C vs V_CE for fixed I_B
- Three regions: Cutoff, Active, Saturation

#### Fixed Bias

- Simple but unstable
- β variation affects operating point

#### Emitter Bias

- Better stability
- Uses emitter resistor

#### Voltage Divider Bias

- Most stable
- Widely used in amplifiers
- Independent of β

#### Common Emitter (CE)

- High current and voltage gain
- 180° phase shift
- Most common amplifier

#### Common Base (CB)

- High voltage gain
- No current gain
- Good high-frequency response

#### Common Collector (CC)

- Current gain only
- Voltage gain < 1
- Used as buffer



#### Structure

- Channel (n or p type)
- Gate (opposite doping)
- Drain and source contacts

#### Operation

- Depletion mode only
- Gate voltage controls channel width
- Pinch-off voltage (V_p)
- Drain current: I_D = I_DSS(1 - V_GS/V_p)²

### MOSFET (Metal-Oxide-Semiconductor FET)

**Enhancement Mode:**

- Normally off
- Threshold voltage required
- Types: n-channel and p-channel

**Depletion Mode:**

- Normally on
- Can be turned off
- Less common

#### Operating Regions

1. **Cutoff**: V_GS < V_th, no current
2. **Linear/Triode**: V_DS < V_GS - V_th
3. **Saturation**: V_DS > V_GS - V_th

#### Drain Current

**Saturation:**

// Example demonstrating Semiconductors.
```

```

**Linear:**

// Example demonstrating Semiconductors.
```

```

### Logic Gates

| Gate | Symbol | Expression | Truth Table        |
| ---- | ------ | ---------- | ------------------ |
| AND  | &      | A·B        | 1 only when both 1 |
| OR   | ≥1     | A+B        | 0 only when both 0 |
| NOT  |        |            | Inverts input      |
| NAND | ↑      | A·B        | Inverted AND       |
| NOR  | ↓      | A+B        | Inverted OR        |
| XOR  | ⊕      | A⊕B        | 1 if different     |
| XNOR | ⊙      | A⊙B        | 1 if same          |

#### Laws

- Identity: A·1 = A, A+0 = A
- Null: A·0 = 0, A+1 = 1
- Idempotent: A·A = A, A+A = A
- Complement: A·A' = 0, A+A' = 1
- Distributive: A(B+C) = AB+AC

#### De Morgan's Theorem
